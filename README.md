# TPER-4-Trabalho-Pr-tico-de-Eng.-de-Requisitos-
O objetivo é apresentar de forma clara, estruturada e acessível a visão geral do sistema, o perfil dos usuários, o levantamento de requisitos (funcionais, não funcionais e regras de negócio) e a representação visual do comportamento e da estrutura do software por meio de diagramas UML (Casos de Uso, Sequência e Atividades).
